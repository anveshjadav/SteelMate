# SteelCalc IS 808 — Structural Steel Weight Calculator
React Native / Expo SDK 51 app

## Quick Start

```bash
# 1. Extract ZIP
unzip SteelCalcIS808.zip
cd SteelCalcIS808

# 2. Install dependencies  
npm install

# 3. Clear any old cache and start
npx expo start --clear
```

Then scan the QR code with **Expo Go** on your phone.

## If you see "transformFile" or Metro errors

```bash
# Delete caches and reinstall
rm -rf node_modules
npm install
npx expo start --clear
```

## Expo SDK Version
- expo: ~51.0.28
- react-native: 0.74.5
- react: 18.2.0

Make sure your **Expo Go** app is updated to the latest version from the App Store / Play Store.
